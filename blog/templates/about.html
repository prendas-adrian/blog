About

This web application was developed with the goal of providing a simple, fast and easy-to-use platform for information management.

The project uses modern web technologies and aims to maintain a clean, intuitive and accessible interface.

It also uses Markdown to store content and Prism to parse and render syntax highlighting for different Markdown styles.

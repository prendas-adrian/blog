Acerca de

Esta aplicación web fue desarrollada con el objetivo de ofrecer una plataforma sencilla, rápida y fácil de utilizar para la gestión de información.

El proyecto utiliza tecnologías web modernas y busca mantener una interfaz limpia, intuitiva y accesible.

Tambien utiliza Markdown para almacenar contenido y Prism para parsear y pintar la sintaxis de los diferentes estilos del Markdown.
